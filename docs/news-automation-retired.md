# Legacy News Automation Retired

Date: 2026-08-08

The previous News automation system has been removed by request. This includes its Vercel Cron trigger, manual trigger endpoint, source-opportunity APIs, RSS/AI generation and publishing modules, image proxy, scripts, dependency and automated tests.

Manual News creation, editing, publishing, archiving and existing News content remain available. Historical News records are preserved, but no remaining runtime path can fetch, generate or automatically publish a new News article.

The retired source is backed up locally under `.backups/news-automation-retirement-20260808-140000/` and is excluded from Git.
